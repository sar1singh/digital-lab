## The 4-Step Vault-First Pre-Flight Research Protocol

Before writing a single script line, outlining a video, or running internet searches for any new Long-Form (L) or Short-Form (S) video, the agent MUST execute this strict 4-step loop:

```
    ┌─────────────────────────────────────────────────────────────┐
    │  STEP 1: QUERY VAULT FIRST (`research/INDEX.md`)             │
    │  Check existing dossiers, dockets, verified metrics & tags   │
    └──────────────────────────────┬──────────────────────────────┘
                                   ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  STEP 2: GAP ANALYSIS & FACT RE-VERIFICATION                 │
    │  Identify verified baseline data vs unknown/missing nodes   │
    └──────────────────────────────┬──────────────────────────────┘
                                   ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  STEP 3: TARGETED 72-HOUR FRESH SEARCH                      │
    │  Search live web strictly for recent developments & deltas   │
    └──────────────────────────────┬──────────────────────────────┘
                                   ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  STEP 4: BIDIRECTIONAL VAULT COMPOUNDING                    │
    │  Sync newly verified sources, dockets & data back to Vault  │
    └─────────────────────────────────────────────────────────────┘
```

---

### Step 1: Query Vault First (`research/INDEX.md`)
* Read `digital-lab/03-content-lab/thinklate/research/INDEX.md` to identify relevant subject clusters.
* Inspect existing dossiers, primary filings, entity profiles, and verified financial metrics.
* **Why:** 60%–80% of economic, regulatory, and corporate data in ThinkLate overlaps across episodes (e.g., Big Tech hyperscaler capex, utility rate-basing laws, SaaS multiples, FTC antitrust rulings). Re-searching known ground wastes tokens and risks factual drift.

### Step 2: Gap Analysis & Fact Re-Verification
* Map out the narrative requirements of the current video against the Vault data:
  - What hard metrics, regulatory dockets, or founder quotes do we already possess with primary URLs?
  - What specific gaps exist? (e.g., exact vote tallies from yesterday's election, latest quarterly 10-Q filing, new state court ruling).

### Step 3: Targeted Live Search (72-Hour Freshness Window)
* Formulate tight, targeted search queries strictly focused on the identified gaps.
* Respect Rule 1 (Temporal Grounding): verify publication timestamps within the last 72 hours for live market/political events.
* Extract primary documentation only (court filings, official regulatory press releases, SEC documents, corporate earnings transcripts).

### Step 4: Bidirectional Vault Compounding
* Every newly verified metric, primary source, or corporate filing discovered during video production must NOT remain trapped inside an isolated video folder.
* The agent must update the relevant dossier in `research/dossiers/` and log the cross-reference in `research/INDEX.md`.
* Result: Every video produced permanently strengthens the research engine for all future videos.
