# ThinkLate Studio — Bright Infinite-Canvas & Excalidraw Recording Deck

One reusable, bright modern web studio for every `@wethinklate` episode (`V0 → V11`) — supporting **both** crisp `16:9` slides AND an **Excalidraw-style Infinite Pan & Zoom Whiteboard** with live pen/highlighter drawing AND 1-click native `.excalidraw` file export.

## How to Use (Zero Server Needed)
1. Open [architect_deck.html](architect_deck.html) in Chrome/Edge.
2. Select your episode (`V0`, `V1`, ..., `V11`) from the top dropdown.
3. **Choose Your Recording Style:**
   - **Crisp Bright Slide Mode (Default):** Clean white dot-grid `16:9` broadcast frames.
   - **Infinite Pan & Zoom Whiteboard (`C`):** All boards arranged on one giant zoomable, draggable canvas (like Excalidraw / Eraser.io / Chai aur Code). Click any board to smooth-zoom into it, drag to pan, scroll to zoom!
   - **Native Excalidraw Export (`⬇ .excalidraw`):** Downloads a native `.excalidraw` file you can drag straight onto [excalidraw.com](https://excalidraw.com/) for full native Excalidraw editing/panning!
4. **Live Recording Hotkeys:**
   - **`H`** — Toggle pure `16:9` **OBS Clean View** (hides topbar & speaker notes)
   - **`C`** — Switch between **Slide Mode** and **Infinite Pan/Zoom Canvas**
   - **`P`** — Toggle live **Pen Drawing** on screen (`E` clears ink)
   - **`L`** — Toggle red **Laser Pointer**
   - **`←` / `→`** or **`Space`** — Advance boards (in Infinite Canvas mode, automatically smooth-pans to the next board!)
   - **`T`** — Stopwatch · **`X`** — Flag retake timestamp · **`F`** — Fullscreen
