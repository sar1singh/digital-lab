## ACT 1: THE TANGIBLE ABSURDITY AND THE UNJUST PARADOX

### COLD OPEN
[VISUAL: Black screen. Sub-bass drop. Cut to frosted windshield of a luxury car at dawn. No avatar until the thesis line.]
*Vocal Delivery: Lean in. Coffee-table secret. Full belly breath before the first word.*
It is a freezing morning. ///
You slide into your brand new car. //
Sixty thousand dollars. //
Your name is on the title. ///
You press the heated seat button. ///
[VISUAL: Dashboard screen glows. Notification card: HEATED SEAT INACTIVE. SUBSCRIBE FOR $18 A MONTH.]
The screen answers. //
Heated seat inactive. //
Subscribe for eighteen dollars a month. ///

### THE SEAT WARMER
[VISUAL: Cutaway of leather seat with glowing copper heating wires already inside.]
Here is the strange part. ///
The heating wires are already inside the seat. //
The copper is already bolted to the battery. //
You already paid for every single piece. ///
But a computer chip in Germany // is holding your seat hostage. ///
That is BMW. //
In twenty twenty-two, they started charging this rent. //
About fifteen pounds a month in the UK. ///

### THE PRINTER
[VISUAL: Home office. Child's homework on the desk. Printer error light blinking red.]
Now walk into your home office. //
Your kid needs to print homework. //
The printer refuses. ///
The cyan cartridge is ninety percent full. //
But it was not made by HP. ///
Overnight, // a silent update called Dynamic Security // killed it. ///
I pulled the court filings on this. //
Same story every time. //
The hardware worked fine yesterday. ///

### THE UNJUST PARADOX
[VISUAL: Kinetic typography slam on navy: YOU PAID 100%. YOU OWN 0%. Sub-bass hit.]
You worked forty hours a week for that money. //
You carried the machine into your own home. //
And now you are a trespasser // inside your own property. ///
[VISUAL: Evidence card: HP CEO interview crop, yellow highlight sweep.]
The HP CEO said this on camera in twenty twenty-four. //
Every printer sold, // he said, // is an investment for them. //
If you do not buy their supplies, // it is a bad investment. ///
Read that again. //
They did not sell you a printer. //
They invested in your living room. //
And they want a monthly dividend // forever. ///
[VISUAL: Avatar P5 slides in, picture-in-picture, bottom-left. Whoosh.]
*Vocal Delivery: Cold. Flat. This is the thesis.*
This is the end of ownership. //
And it is not an accident. ///
I will show you the math behind it. ///
Then I will show you it is a hundred years old. ///
And then, // how to get out. ///

## ACT 2: THE WALL STREET MACHINE AND THE TOLL BOOTH

### THE PAY-PER-FLUSH TOILET
[VISUAL: Cutaway suburban house. Coin slot bolted onto a toilet. Hand holds a wrench. Water main valve snaps shut.]
Let me give you a picture first. ///
Imagine you buy a house. //
Five hundred thousand dollars. //
You get the deed. //
You get the bricks, // and the pipes. ///
Then the builder bolts a coin slot // onto your toilet. ///
Fifty cents per flush. ///
You grab a wrench to fix the valve yourself. //
The water main shuts off by itself. ///
That sounds like a comedy sketch. ///
Until you look at Mercedes. ///
[VISUAL: Evidence card: Mercedes Acceleration Increase price page, $1,200 per year highlighted.]
Twelve hundred dollars a year // to unlock faster acceleration. //
In a car they already sold you. ///
Tesla charges two thousand dollars // for a similar speed boost. ///

### TRACE THE MONEY
[VISUAL: Animated chart. Two bars rise from the same factory. Left bar 1.5x. Right bar 15x.]
So why is every CEO doing this? ///
Because of one number. //
Follow the money with me. ///
When a company sells you something once, // Wall Street gets nervous. ///
A recession hits, // and people stop buying. ///
So investors pay very little for that company. //
About one and a half times its yearly sales. ///
Now flip the same company // into a subscription. ///
Same product. //
Same factory. //
But now it bills your card every month. ///
Wall Street gives it a new name. //
Recurring revenue. ///
And pays fifteen times its sales // or more. ///
Do the math. ///
Say a company is worth one and a half billion dollars. ///
The CEO moves eight hundred million of sales // into subscriptions. ///
Wall Street re-prices the whole company. //
Nearly ten billion dollars. //
Overnight. ///
No new invention. //
No new feature. //
Just a paywall // on something you already own. ///
The CEO's stock options vest. //
And you get the bill. ///
This is not greed alone. //
It is a math problem // that rewards taking ownership away. ///

## ACT 3: THE HUNDRED-YEAR CYCLE AND THE LIGHTBULB CARTEL

### GENEVA, 1924
[VISUAL: Single vintage map pan of Europe, zoom into Geneva. Sepia lightbulb glow. Smoke-filled meeting room.]
Now you might think this is new. ///
It is not. ///
Go back to December twenty-third, // nineteen twenty-four. ///
Geneva, Switzerland. ///
The biggest lightbulb makers on Earth // meet in secret. //
Osram. //
Philips. //
General Electric. ///
They had a problem. ///
Their bulbs were too good. //
A bulb could burn for twenty-five hundred hours. //
Some lasted even longer. ///
[VISUAL: The Centennial Light, glowing in a California fire station.]
There is a bulb in California // burning since nineteen oh one. ///
It has not died in over a hundred years. ///
If nothing breaks, // nobody comes back to buy. ///
Sales flatlined. ///

### THE PHOEBUS CARTEL
So they formed a group // called the Phoebus Cartel. ///
Their secret rule was simple. //
Every bulb must die // after one thousand hours. ///
Factories tested bulbs in labs. //
Make one that lasts too long, // and you pay a fine. ///
Think about that. //
They paid engineers // to make a worse product. ///
That is where built-in failure was born. ///

### THE DIGITAL VERSION
[VISUAL: Cracked plastic dissolves into a cloud server icon. One line of code: REVOKE ACCESS. Sub-bass hit.]
Now fast forward. ///
In the twentieth century, // you had to engineer plastic to crack. ///
The twenty-first century is easier. ///
Build great hardware. //
Then write three lines of code // on a cloud server. ///
Revoke your access. //
Press enter. ///
No cracked plastic. //
No evidence. ///
The lightbulb cartel // went digital. ///

## ACT 4: THE GLOBAL ANCHOR AND THE ESCAPE PLAN

### THE PARENTAL BASELINE
[VISUAL: Split screen. Left: 1990 garage with a stereo and toolset. Right: modern phone screen full of subscription renewals.]
So what does this look like for real people? ///
Think of your father, // thirty-five years ago. ///
Modest salary. //
He bought a car. //
A stereo. //
A toolset. ///
Some of it still works in the garage today. ///
Now look at you. //
Maybe a great salary. //
Maybe a tech job. ///
The average American pays // two hundred nineteen dollars a month // in subscriptions. ///
That is over twenty-six hundred dollars a year. //
Just to keep what you already use running. ///

### THE US ANCHOR
[VISUAL: Tractor in a field, dashboard error light, slow 2 mph crawl. Cut to FTC v. Adobe complaint page.]
In America, // it gets physical. ///
Farmers pay hundreds of thousands // for a John Deere tractor. ///
A thirty-dollar sensor breaks. //
The tractor crawls at two miles an hour. ///
Only a dealer's laptop // can unlock it. //
And the dealer charges by the hour // to press one button. ///
In June twenty twenty-four, // the FTC sued Adobe. ///
Customers were trapped in annual plans. //
Cancel early, // and pay half the remaining bill. ///

### THE INDIA ANCHOR
[VISUAL: Indian city street. Electric scooter dashboard with a PRO PACK paywall card. Then a DTH remote versus a wall of streaming app icons.]
Now India. //
Because this is not a Western problem. ///
Electric scooters from Ola and Ather // are built with reverse mode. //
Hill-hold is built into the motor. //
But features like these // sit behind paid software packs. ///
Remember cable TV? //
Around three hundred rupees a month // for hundreds of channels. ///
Today, // five streaming apps. //
A thousand to fifteen hundred rupees. //
With ads you cannot skip. ///
And the darkest one. ///
[VISUAL: Delivery rider on a scooter. Phone screen locks with a red padlock. Sub-bass hit. Hold the silence 2 seconds.]
*Vocal Delivery: Slow down. Drop the pitch. Let the silence sit before the next line.*
Many people in smaller Indian cities // buy phones on easy monthly payments. ///
The loan app installs a lock inside the phone. ///
Miss a payment by a couple of days, // and the screen locks. ///
A delivery rider's phone // becomes a plastic brick. ///
His map. //
His orders. //
His income. //
Gone. ///

### THE CLOSED LOOP AND THE ESCAPE PLAN
[VISUAL: Return to the opening dashboard. Same car, same frosted glass, same button. Avatar P5 holds arms crossed.]
So back to that cold morning. ///
Same car. //
Same dashboard. //
Same button. ///
The question is no longer // how much you earn. ///
It is how much of your life // you actually own. ///
[VISUAL: Three-card kinetic typography: SOFTWARE YOU KEEP. HARDWARE YOU FIX. STOP RENTING.]
Here is your escape plan. //
Three moves. ///
One. //
Choose software you can keep. ///
DaVinci Resolve instead of Adobe. //
Obsidian instead of cloud notes. //
Files on your own drive. ///
Two. //
Back hardware you can fix. ///
Framework laptops. //
Fairphone. //
Right to repair laws. ///
Three. //
Stop being the renter. ///
Cut the recurring bills. //
Put your money // into things you control. ///
[VISUAL: Avatar P5 held 2 to 3 seconds. Clean fade to black.]
*Vocal Delivery: Warm. Quiet. A friend signing off.*
Do not pay rent on your own life. ///
See you next time. ///
