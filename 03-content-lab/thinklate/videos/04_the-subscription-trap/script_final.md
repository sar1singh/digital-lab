## Why did a sixty-thousand-dollar car ask for eighteen dollars to warm a seat?

[SFX: Wind howling. Car door thuds shut. Seatbelt clicks. Then absolute silence.]
[VISUAL: Anchor frame one. Frosted windshield and glowing luxury dashboard at dawn. Slow 3 percent push. No avatar.]
*Delivery: Lean in. Coffee-table secret. Full belly breath before the first word.*
In July twenty twenty-two, // BMW started charging rent on heated seats. ///
Not at a shop. // Not at a dealership. // Through the car's own screen. ///
South Korea. // The United Kingdom. // Germany. // South Africa. ///
About fifteen pounds a month, // or a hundred and fifty a year. ///

[SFX: One soft digital beep, then a dull refusal buzz.]
Here is what made people furious. ///
The heating wires were already inside the seat. //
Copper. // Relays. // Switches. // Bolted in at the factory. ///
You had paid for every gram of it. ///
But a software flag said, // "Not unless your card keeps billing." ///
BMW did not forget to install a feature. //
They installed a hostage // in your own front seat. ///

[SFX: All sound cuts out. One and a half seconds of dead silence.]
Now, if you are rolling your eyes, // fair. ///
It is a seat warmer. // Who cares? ///
Except this was not a prank. ///
It was a test. // And somebody was taking notes. ///

## Who decided your printer should die overnight?

[SFX: Printer head grinds, stutters, then a sharp error beep.]
[VISUAL: Anchor frame two. Dim home office, a child's homework on the desk, printer glowing red.]
Because one company had already tried this for years. //
And it did not start with a car. ///
Meet HP. ///
In twenty sixteen, // HP pushed a quiet update to its printers. //
It was called Dynamic Security. ///
Owners woke up to a dead machine. //
The ink cartridge was full. //
It just was not made by HP. ///

No warning. // No vote. // Just an update, // overnight. ///
You did not buy a printer. //
You bought a printer // that audits your ink. ///
Italy's competition regulator fined HP ten million euros. //
That was twenty twenty. ///
Consumer groups in Belgium, // Spain, // Italy, // and Portugal got a settlement. ///
HP paid. // The business model stayed. ///

[VISUAL: Evidence card. HP CEO interview crop, yellow highlight sweep across the quote.]
In twenty twenty-four, // HP's own CEO said the quiet part out loud. ///
Every time a customer buys a printer, // he said, //
it is an investment for HP. ///
If that customer does not print enough, // or does not use HP supplies, // it is a bad investment. ///
Read that slowly. ///
You paid HP. // And somehow // you became HP's investment. ///
And the moment you buy cheaper ink, // you become a bad one. ///

A cold seat is an insult. //
A dead printer is an afternoon. ///
But what happens // when the locked machine // is the one that feeds a family? ///

## What happens when the locked machine is a tractor?

[SFX: Diesel engine idling, then it coughs and dies. Wind across an empty field.]
[VISUAL: Anchor frame three. Nebraska cornfield at dusk, low fog, a lone silhouette beside a silent combine.]
A hog farmer in Nebraska // stood in front of his state lawmakers. // Twenty seventeen. ///
His equipment had broken down. //
He told them there is no time // to wait for a dealer. ///
Farmers can often swap a part themselves. ///

But the machine would not accept the new part // until a dealer plugged in a laptop // and approved it. ///
The price? // Two hundred thirty dollars to show up. //
Plus a hundred thirty an hour. //
To plug in one cable. ///
Whose tractor was it? ///

[SFX: Keyboard clatter. A soldering iron hisses.]
[VISUAL: Anchor frame four. Hacker in a dark room soldering a dashboard, terminal code glowing behind him. File: hacker_noir_plate.jpg]
So farmers did what cornered people always do. //
They went looking for outlaws. ///
Hackers in Eastern Europe // were already selling cracked tractor software. ///
Forums in Ukraine. // Pirate firmware. // And the tractor wakes up. ///
Think about how backwards that is. ///
An American farmer // downloads cracked code // so he can fix his own machine. ///

Because the legal route // is a dealer's laptop. ///
John Deere's license agreement // forbids nearly all repair. //
Backed by copyright law. ///
The pirate respects the farmer's ownership // more than the company does. ///

## Why would any CEO want this?

[VISUAL: Animated chart asset. Two bars rise from the same factory on an illustrative one billion in sales. Left bar one point five times, illustrative. Right bar six point seven times, median public software multiple. Source footnote on screen.]
[SFX: Stock ticker tape rattles. A cash register chime lands on the right bar.]
So who signed off on all this? ///
Not a villain in a cape. //
A spreadsheet. ///
Wall Street prices every company with a multiplier. ///
Sell a tractor once, // and investors get nervous. //
What if a recession hits? //
What if nobody buys next year? ///
So that company is worth // maybe one or two times its yearly sales. ///

Now watch the trick. ///
Same tractor. // Same factory. // Same farmer. ///
But now a monthly bill unlocks it. ///
The accountants give the revenue a new name. //
Recurring. ///
And investors start pricing it like software. //
Software gets six, // seven, // sometimes far more times revenue. ///
Not for a better tractor. //
For a customer who cannot leave. ///

Take a company with one billion in sales. //
Worth about one and a half billion. ///
Convince investors it is a subscription business, //
at six and a half times, //
and it is worth nearly seven. //
Overnight. ///
No new invention. // No new feature. //
Just a paywall // on something you already own. ///
And the CEO's stock options? //
Their value jumps. ///

[SFX: Music drops out. One and a half seconds of dead silence.]
That is not simple greed. //
Greed would be easier to fight. ///
It is a scoreboard // that pays executives // to take your ownership away. ///

## Is this actually new?

[SFX: A clock ticking. Low murmur in German and French. A match strikes.]
[VISUAL: Anchor frame five. Smoky Geneva meeting room, winter nineteen twenty-four, men around a table studying one glowing bulb.]
Because the idea is a hundred years old. ///
Winter, // nineteen twenty-four. // Geneva. ///
A room full of men // who sold the world its light. ///
Osram from Germany. // Philips from Holland. // General Electric from America. ///
Rivals on paper. // Partners in secret. ///
They had one problem. ///
Their lightbulbs were too good. ///

Some burned twenty-five hundred hours. //
There is one in a California fire station // that has glowed, almost nonstop, // since nineteen oh one. ///
Great product. // Terrible business. ///
Nobody comes back to buy a bulb that never dies. ///
So they signed a pact. // They called it Phoebus. ///
Every bulb would be built to die // after one thousand hours. ///
They tested the bulbs. //
Make a bulb that lasts too long, // and you were fined. ///
Fined // for making a better product. ///

[SFX: Dead silence. Two seconds. Then a single lightbulb filament snaps.]
A hundred years later, // nobody needs a secret meeting in Geneva. ///
No weak filament. // No cracked plastic. // No evidence. ///
Just one line of code // and a server that says, // "Access revoked." ///
Same incentive. // Better paperwork. ///

## What does it cost the person who cannot pay?

[SFX: Scooter engine in night traffic. A phone buzzes. Then a heavy lock clicks.]
[VISUAL: Anchor frame six. Night street in an Indian city, delivery rider on a scooter, phone screen locked behind a red padlock.]
And if you think this only hurts people with BMWs, // go to a small town in India. ///
Take a delivery rider // buying a smartphone on easy monthly payments. ///
Phones sold this way can carry a lock. //
The lender controls it. ///
He is late on one payment. // A day. // Maybe two. ///
The screen goes dark. ///

*Delivery: Slow down. Drop the pitch. Let each line land.*
His map. // His orders. // His income. ///
Behind a padlock. ///
The loan app is not asking for the money. //
It is holding his job hostage // until the money arrives. ///
In America, // regulators saw the same pattern. //
In June twenty twenty-four, // the government sued Adobe. ///
It said customers were stuck in annual plans. //
Cancel early, // and pay half of what is left. ///

## What happened to the seat?

[SFX: Soft seat-warmer click. A low electrical hum begins.]
[VISUAL: Return to anchor frame one. Same frosted dashboard, same button, a faint orange glow now spreading.]
So what happened to the seat? ///
In September twenty twenty-three, // BMW quietly dropped it. ///
No new conscience. // Enough owners said no, // loudly. ///
Farmers got a law too. //
Colorado, // twenty twenty-three, // the first state to write one for tractors. ///
Minnesota and California passed their own // for phones and laptops. ///
It is the first time // a few of them blinked. ///

But look at what they were willing to try. ///
A seat. // A printer. // A tractor. // A phone. ///
Whatever you own // is one software update // from becoming a lease. ///
The seat is warm again. //
The question was never the heat. ///
It was whose seat it is. ///

[SFX: Dashboard chime fades into the hum. Fade to black.]
Next time a screen asks for rent on something you own, //
remember who is holding the key. ///
See you next time. ///
