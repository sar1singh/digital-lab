## How does a company lose eighty billion dollars typing text?

[SFX: Wall Street opening bell rings. Murmur of a crowded stock trading floor. A sudden gavel strike. Then absolute silence.]
[VISUAL: Anchor frame one. Dimly lit New York Stock Exchange floor at dawn. A glowing blue trading terminal displaying a digital SEC Form S-1 prospectus with ticker symbol ANT. Slow 3% push.]
*Delivery: Lean in. Conversational, incredulous friend over drinks. Full belly breath before the first word.*
In the summer of twenty twenty-six, // a company called Anthropic did something unprecedented. ///
They filed paperwork with the SEC // to sell shares on Wall Street. ///
The ticker symbol? // ANT. ///
The target valuation? // Up to two trillion dollars. ///
Two trillion // with a T. ///

[SFX: Soft digital terminal blip. Paper rustle.]
Remember Anthropic? ///
They were the idealistic researchers // who broke away from OpenAI. //
Because they believed commercializing AI // was moving too fast. //
And too dangerous for humanity. ///
Now, // they are rushing to the Nasdaq // to sell shares to your dentist // before the quarterly electric bill arrives. ///

[SFX: One and a half seconds of dead silence.]
Because when you open page forty-eight // of their S-1 registration statement, //
the number that jumps off the page // is not their revenue. ///
Their revenue looked impressive: // sixteen point three billion dollars // in just the first six months. ///
The number that hits you // is the net loss. ///
Eighty point seven // billion dollars. ///
In six months. ///
Read that again. ///
How does a software company // lose eighty billion dollars // answering text prompts? ///

## Whose money is actually in the circle?

[SFX: Computer fan whirls up into an industrial server whine. Low electrical drone.]
[VISUAL: Anchor frame two. High-altitude glass boardroom overlooking a foggy skyline at midnight. Three figures in dark suits sliding glowing briefcases around a triangular glass table.]
To understand that eighty-billion-dollar crater, // you have to follow the money. ///
And when you trace the cash, // you do not find a business. ///
You find a carousel. ///
Watch how the machine works. ///

Amazon invests billions // into Anthropic. //
Microsoft invests billions // into OpenAI. ///
Do you think that cash // sits in a corporate checking account? ///
Within seventy-two hours, // that money is wired directly back. //
To Amazon Web Services // and Microsoft Azure. //
To rent server racks. ///
And what do Amazon and Microsoft // do with that cash? ///
They wire it straight to Santa Clara // to buy hundreds of thousands // of Nvidia GPUs. ///

[SFX: Cash register chime lands on a heavy sub-bass thud.]
[VISUAL: Evidence plate. SEC 10-K cloud commitment footnote with bold yellow highlight.]
Nvidia reports record earnings. //
Wall Street pushes their market cap // into the stratosphere. //
And venture capitalists celebrate, // because the startup they funded // just booked "record revenue." ///
Everyone reports growth. //
Everyone gets a bonus. ///
And the only thing actually moving // is the same ten billion dollars // spinning in a circle. ///

Like a financial washing machine. ///
There is only one problem. ///
Where is the paying customer? ///
A twenty-dollar subscription // that writes cover letters // does not pay for a nuclear reactor. ///

## Who pays the six-hundred-billion-dollar electric bill?

[SFX: Calculator mechanical clicking. High-voltage power transformer hum.]
[VISUAL: Animated chart asset. Illustrative comparison bar: Global Enterprise Software Market ($350B) vs Annual AI Infrastructure Revenue Demand ($600B). Red flashing deficit bar.]
A partner at Sequoia Capital // named David Cahn // sat down with a calculator. ///
And he asked the question // nobody in Silicon Valley // wanted to put on a slide. ///
The math is ruthless. ///

If Big Tech spends // three hundred billion dollars // building AI data centers, //
those chips do not last forever. ///
They burn out. // They become obsolete // in four to five years. ///
To pay for the depreciation, // the cooling, // and the utility bills, //
the AI industry needs to generate // six hundred billion dollars in revenue. //
Every single year. ///

[SFX: Music drops completely out. Absolute dead silence. Two seconds.]
Now look at the entire planet. ///
The total amount of money // spent on all business software on Earth // last year //
was about three hundred and fifty billion dollars. ///
Every database. // Every CRM. // Every operating system. // Combined. ///
To justify this bubble, // AI would have to replace // every software company on Earth. //
Twice over. // Overnight. ///
That is not a forecast. ///
That is mathematical fiction. ///

## Have we seen this movie before?

[SFX: Vintage typewriter clatter. The crackle of an old telephone switchboard line.]
[VISUAL: Anchor frame three. Split composition: 1999 telecom fiber ditch alongside a modern desert GPU data center with cooling steam.]
If you think this is brand new, // welcome to nineteen ninety-nine. ///
Telecom companies // like WorldCom and Global Crossing // borrowed hundreds of billions. ///
They dug trenches across continents. //
They laid millions of miles // of fiber-optic glass cables // under every highway and ocean. ///
They told Wall Street // that internet traffic was doubling // every ninety days. ///

The traffic was real. //
The business model was a fantasy. ///
In two years, // ninety percent of telecom startups // filed for bankruptcy. ///
Trillions of dollars // in paper net worth // vanished into thin air. ///

[SFX: Distant thunder. Low sub-bass rumble.]
But look at what happened // when the dust settled. ///
The glass cables // were already in the ground. ///
New operators bought them // for pennies on the dollar. ///
And ten years later, // that bankrupt, dirt-cheap infrastructure //
gave birth to Netflix, // YouTube, // and modern cloud computing. ///
The bubble popped. //
The plumbing stayed. ///

## Who holds the bag when the bell rings?

[SFX: Heavy steel safe door swinging shut. Locking mechanism clicks.]
[VISUAL: Anchor frame four. Return to the dark trading terminal floor. The ticker symbol ANT glowing dimly as the screen fades toward deep slate navy.]
And that brings us right back // to Anthropic's S-1 filing. ///
The founders of these AI labs // are not foolish. //
They are world-class mathematicians. ///
They can see the charts. ///
They know the cost of training models // is compounding exponentially. ///
While the price of basic text generation // is racing toward zero. ///

The smart money knows // the clock is running out. ///
When an AI bubble bursts, // you do not bet against the technology. ///
You follow the physical assets. ///
The losers will be the companies // burning eighty billion dollars // to answer corporate emails. ///
The winners // will be the companies that own the power plants, //
the local data that cannot be scraped, //
and the sovereign infrastructure // that survives the crash. ///

[SFX: Final trading bell chime fades into deep sub-bass drone.]

Just remember: //
When the carousel stops, //
make sure you are not the one // holding the bill. ///
See you next time. ///
