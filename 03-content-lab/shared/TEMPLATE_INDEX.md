## 🏗️ The 4-Track Layered Stacking Rules (Paivio's Law)

Every scene MUST maintain active multi-layer motion:

```
┌────────────────────────────────────────────────────────────────────────┐
│ TRACK 4: Kinetic Typography / Micro-Motion Pill / Rubber Stamp Slam    │
├────────────────────────────────────────────────────────────────────────┤
│ TRACK 3: Primary Remotion Motion Card (ProRes 4444 MOV with Alpha)     │
├────────────────────────────────────────────────────────────────────────┤
│ TRACK 2: Dynamic Gaussian Focus Blur (sigma 14 during card windows)    │
├────────────────────────────────────────────────────────────────────────┤
│ TRACK 1: Living Gameplay Canvas (ACBF_Gameplay_2.mp4 or Moving Stock)  │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Track 1 (The Living Spine):** Never hold a motionless image. Gameplay or 4K stock video moves continuously in the background.
2. **Track 2 (Focus Pull):** Blur is **dynamic** (`between(t, cue_start, cue_end)`). When a card appears, gameplay blurs to sigma 14. During breathing gaps between cards, gameplay snaps back to sharp focus.
3. **Track 3 (Primary Remotion Card):** Exported strictly as Apple ProRes 4444 `.mov` with 12-bit alpha (`yuva444p12le`). Never loop a flat PNG!
4. **Track 4 (Concurrent Micro-Motion):** Kinetic typography slam, pill badge, or rubber stamp that enters 0.5s–1.0s after the card to create active dual-state visual progression.

## 📝 Script Timeline Annotation Syntax

When writing scripts in `.md`, agents insert cues using this standard syntax:

```markdown
<!-- CUE: MagnifyingGlassDoc | start: 00:14.50 | duration: 4.0 | props: {"documentTitle": "SF HOUSING CODE // SEC 402", "stampText": "VIOLATION"} -->
The founders were 72 hours from being evicted, and subleasing without a license was an immediate misdemeanor.

<!-- CUE: WatchMojoCountdown | start: 00:22.00 | duration: 3.5 | props: {"rank": "#01", "title": "THE ASSET ARBITRAGE", "category": "SYSTEM RULES"} -->
Rule number one: Never buy physical real estate when you can monetize someone else's spare bedroom.
```

The automated batch production tool (`.agents/tools/batch_produce_video.py --script script.md`) automatically reads these annotations, renders the ProRes cards, and compiles the final 4-track master video!
